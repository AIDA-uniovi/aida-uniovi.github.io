# AIDA · Artificial Intelligence and Data Analysis

Static website of the **Artificial Intelligence and Data Analysis (AIDA)** research unit at the University of Oviedo.

## Website

The site is published with GitHub Pages at:

https://aida-uniovi.github.io/

## Structure

- `index.html`: home page
- `team.html`: links to the three constituent research groups
- `publications.html`: official publication records
- `projects.html`: funding and project information
- `phd.html`: doctoral theses
- `contact.html`: contact details
- `assets/`: styles, scripts and vector images

The site is intentionally framework-free and uses only HTML, CSS and a small amount of JavaScript.
